## Reference folders

- [`architecture/`](architecture/) contains the supported architecture and
  v1.0.0 compatibility records.
- [`adr/`](adr/) contains architecture decision records.
- [`hardware/`](hardware/) contains the confirmed wiring and electrical profile.
- [`validation/`](validation/) contains software and Raspberry Pi validation
  evidence and checklists.
- [`project-history/`](project-history/) contains audits and the completed V4
  phase plan. These files explain prior decisions but are not installation
  instructions.
