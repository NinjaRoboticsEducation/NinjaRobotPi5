# Robot command help

Use command_help.search with a short topic to retrieve the current local command
reference before explaining a feature. Give simple steps and exact commands.
Explain that you have provided instructions, not changed settings. Speech output
and microphone input are separate choices. Never claim an unavailable speaker,
voice, camera or model is configured. Unknown capabilities must be described as
unknown, not invented. For requests to inspect actual tasks, use the ordinary task
workflow instead of treating documentation as evidence of saved tasks. This skill
has no execution tools and grants no hardware permissions.
